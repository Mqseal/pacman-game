# AI Collaboration Log

## Tools used
- GitHub Copilot Chat in Codespaces, ChatGPT on the Web 

## A prompt that worked well
- "Help me implement dot collection and wall collision for my Pac-Man game step by step.
- Why it worked: The prompt was specific and included the classes and feature I wanted to implement.

## A prompt that did not work
- "Write the whole feature at once."

## What went wrong:
- The response was too large and caused confusion while debugging.

## How I recovered:
- I switched to implementing one function at a time and tested after every change.

## Code I rejected
- I rejected more complicated AI suggestions involving extra helper classes because they were unnecessary for this project.

## What I'd do differently next time
- I would start testing earlier after each smaller change instead of waiting until several files were modified.
