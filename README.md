#pacman-game

A simple command-line Pac-Man game where the player collects dots and avoids ghosts.

## Features
- Move Pac-Man
- Collect dots
- Ghost movement
- Collision system
- Score tracking

## Current Status

**Implemented Features**:
- Pac-Man movement using WASD-style controls
- Score tracking through the PacMan class
- Pac-Man initialization with position, lives, and score

**Stubbed (compile but not fully implemented yet)**:
- Ghost movement and AI
- Collision handling
- Maze wall and dot logic
- Power mode
- Multiple levels

**Known Issues**:
- The full game loop is still basic.
- Ghost behavior has not been implemented yet.
- Maze collision and dot collection are still in progress.
- Power mode and level switching will be added later.
