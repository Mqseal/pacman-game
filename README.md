#pacman-game

A simple command-line Pac-Man game where the player collects dots and avoids ghosts.

## Current Status

**Implemented Features**:
- Pac-Man movement
- Score system
- Dot collection
- Basic wall collision
- Maze logic
- Automated tests

**Stubbed / incomplete**:
- Ghost AI
- Power mode
- Multiple levels
- Ghost collision system

**Known Issues**:
- Ghost behavior is not implemented yet
- Power pellets are not implemented yet
- The game loop is still basic

**AI Assistance**:
- AI assistance was used for the dot collection and wall collision feature
- See `docs/ai_collaboration.md` for the collaboration log
